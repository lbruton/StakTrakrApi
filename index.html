StakTrakr API

Free, keyless precious metals price data: spot, retail and Goldback feeds as static JSON.
Used by www.staktrakr.com · App source: lbruton/StakTrakr · Data repo: lbruton/StakTrakrApi

Free and public. No key, no account.

Base URL

https://api.staktrakr.com/data/v2/Every path below is relative to this base. Start from manifest.json.

Endpoints

PathReturns
manifest.jsonMetals, coin slugs, vendors and endpoint templates
providers.jsonVendor product URLs per coin
spot/latest.jsonCurrent spot price for all five metals
spot/{metal}/latest.jsonOne metal, with 24-hour change
spot/{metal}/intraday.jsonRolling 24 hours of 15-minute OHLCA
spot/{metal}/{YYYY}/{MM}/{DD}.jsonHourly OHLCA for one UTC day
spot/{metal}/{YYYY}/{MM}.jsonDaily OHLCA for one month
spot/history/{N}d.jsonDaily OHLCA per metal; N is 7, 30 or 90
retail/latest.jsonMedian, low and high price for every coin
retail/{slug}/latest.jsonPer-vendor prices for one coin
retail/{slug}/intraday.jsonRolling 24 hours of 15-minute windows, per vendor
retail/{slug}/{YYYY}/{MM}.jsonDaily aggregates for one month
retail/{slug}/history-{N}d.jsonDaily aggregates; N is 7, 30 or 90
retail/vendors/index.jsonVendor list
retail/vendors/{vendor}.jsonEvery coin price from one vendor
goldback/latest.jsonG1 rate in USD and denomination prices
goldback/intraday.jsonHourly G1 rate for the last 72 hours
goldback/{YYYY}/{MM}.jsonDaily G1 rate for one month
goldback/history-30d.jsonDaily G1 rate for 30 days

Path values

{metal}xau Gold, xag Silver, xpt Platinum, xpd Palladium, xcu Copper
{slug}A coin slug from the manifest, for example ase, age, goldback-utah-g1
{vendor}A vendor ID from the manifest, for example apmex, jmbullion
DatesUTC. Four-digit year, zero-padded month and day

Example: current spot price

const res = await fetch("https://api.staktrakr.com/data/v2/spot/xag/latest.json");
const { generated_at, stale_after, data } = await res.json();
console.log(data.price, data.change_24h_pct);
// 53.92 -0.17

Example: retail prices for one coin

const res = await fetch("https://api.staktrakr.com/data/v2/retail/ase/latest.json");
const { data } = await res.json();
console.log(data.median, data.low, Object.keys(data.vendors));

Notes

EnvelopeEvery v2 file returns v, generated_at, stale_after (seconds) and data
TimestampsTime-series points carry t (ISO 8601 UTC) and ts (Unix seconds)
UnitsSpot in USD per troy oz. Retail in USD per coin
UpdatesEvery 15 minutes. Cache responses; the data does not change between publishes
CORSAccess-Control-Allow-Origin: *. Browser fetch() works
Legacy v1data/api/ is still published for older clients. Build new clients against v2
AvailabilityServed by GitHub Pages, with no SLA. The data comes with no warranty of accuracy
Data from StakTrakr. Spot prices from MetalPriceAPI, retail prices from dealer product pages, Goldback rates from goldback.com. Source: StakTrakr · StakTrakrApi
